# Manual de Usuario - TecnoReview

## 1. Información general

**Nombre del proyecto:** TecnoReview

**Tipo de sistema:** Plataforma web de reseñas y comparación tecnológica.

**Objetivo:** Permitir a los usuarios consultar productos tecnológicos, buscar información, revisar opiniones y valoraciones, comparar productos y consultar establecimientos relacionados.

**Estado:** En desarrollo.

---

# 2. Introducción

TecnoReview es una plataforma web orientada a la consulta y comparación de productos tecnológicos.

El sistema permite que los usuarios encuentren información sobre diferentes productos, consulten sus características, revisen opiniones de otros usuarios y realicen comparaciones.

Además, la plataforma contempla información sobre establecimientos donde pueden encontrarse productos tecnológicos y permite consultar su ubicación mediante Google Maps.

---

# 3. Requisitos para utilizar el sistema

Para utilizar TecnoReview se necesita:

- Un computador, tablet o teléfono.
- Un navegador web actualizado.
- Conexión a Internet.
- JavaScript habilitado en el navegador.

Algunas funciones requieren una cuenta registrada.

---

# 4. Tipos de usuario

TecnoReview contempla los siguientes perfiles:

| Perfil                           | Descripción |
|---                               |---|
| Visitante                        | Puede consultar información pública sin iniciar sesión. |
| Usuario registrado               | Puede utilizar funciones relacionadas con reseñas y valoraciones. |
| Administrador                    | Puede administrar información del sistema según sus permisos. |
| Representante de establecimiento | Puede gestionar información de establecimientos según los permisos definidos. |

Los permisos definitivos pueden variar de acuerdo con la implementación final del sistema.

# 28. Problemas comunes
No puedo iniciar sesión

Verificar:

Correo electrónico.
Contraseña.
Conexión a Internet.

Si el problema continúa, se debe verificar que la cuenta haya sido registrada correctamente.

No encuentro un producto

Se recomienda:

Revisar la escritura del nombre.
Utilizar términos más generales.
Revisar las categorías.
Revisar los filtros.
No puedo publicar una reseña

Verificar que:

La sesión esté iniciada.
El producto exista.
El formulario esté completo.
La información ingresada sea válida.
No puedo administrar un producto

Es posible que el usuario no tenga los permisos necesarios.

Las operaciones administrativas están restringidas según el rol.

No aparece la ubicación

Verificar:

Que el establecimiento tenga información de ubicación.
Que exista conexión a Internet.
Que la integración con Google Maps esté disponible.

---

# 29. Uso responsable de las reseñas

Las reseñas deben utilizarse de manera responsable.

Se recomienda:

Escribir opiniones relacionadas con el producto.
Utilizar lenguaje respetuoso.
Evitar información personal de terceros.
Evitar contenido ofensivo.
Proporcionar información útil para otros usuarios.

El sistema podrá establecer reglas adicionales para la publicación de contenido.

# 30. Privacidad y seguridad

Los usuarios deben evitar compartir públicamente información sensible dentro de las reseñas.

No se deben publicar:

Contraseñas.
Datos bancarios.
Información privada de terceros.
Credenciales de acceso.
Claves de API.

Las credenciales de acceso deben mantenerse privadas.
