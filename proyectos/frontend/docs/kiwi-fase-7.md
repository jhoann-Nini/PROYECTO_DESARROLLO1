# Kiwi V3 · Fase 7: comparador

Referencia: `docs/diseno-v3-kiwi/DISENO.md`, `tokens.css` y `pantallas/Comparador.html`.

Se adaptó la apariencia de `ComparadorCliente` al sistema Kiwi: superficies con bordes, divisores punteados, tipografía de títulos y productos en mayúsculas mediante CSS, campo de búsqueda con `Input`, acciones con `Button` y señales con `Tag`. Los valores sin dato se muestran en cursiva y las filas con diferencias usan la superficie seleccionada. No se cambiaron rutas, textos, nombres accesibles, selección, filtros, comparabilidad ni llamadas a servicios.

Validación: `npm test` (94 archivos y 1375 pruebas aprobados) y `npm run build` (aprobado). No se actualizaron pruebas.
